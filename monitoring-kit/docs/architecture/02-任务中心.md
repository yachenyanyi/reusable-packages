# 任务中心（Task Center）

## 目的

表达“为什么监测、监测哪些来源、何时执行”，并管理任务定义与触发，不暴露抓取实现细节。

## 公开能力

- 创建和修订 `TaskDefinition`。
- 启用、暂停任务。
- 手动触发全量、增量或指定对象复查。
- 维护执行周期。
- 查询任务最近运行摘要。

## TaskDefinition

- 任务名称、业务场景和负责人。
- 来源范围与对象范围。
- 运行模式：全量、增量、指定对象复查。
- 执行周期和有效时间。
- 分析方案引用：关键词规则、AI 方案等。
- 报告与预警方案引用。

## 不变量

- Task 只引用来源 ID，不复制来源配置。
- Run 启动时冻结任务、来源和策略的实际版本。
- 暂停任务阻止新 Run，不中断已经运行的 Run。
- 调度触发与人工触发进入同一个采集引擎接口。

## 隐藏知识

Cron 表达式、调度器实现、队列发布方式、数据库事务和运行后端。

## 非目标

不发现 URL、不执行采集、不决定重试、不保存网页快照。

## 依赖与使用方

被三个业务场景和后台/API 使用；依赖数据源资产目录、采集引擎、权限和审计。
