# 审计追踪（Audit Trail）

## 目的

记录影响业务结论、配置、安全和外部系统的关键动作，提供不可抵赖的时间线。

## 公开能力

```text
record(AuditEvent)
query(AuditQuery) → AuditTimeline
```

核心采集引擎提供可选的 `AuditSink` 钩子，至少记录 Run 接受和终态；审计存储由宿主或适配器实现。钩子失败不能回滚已经提交的采集事实。

## 应记录的事件

- 来源、任务、规则和模型方案变更。
- Run 的创建、取消和异常终止。
- Finding 的确认、驳回和 Case 状态转换。
- 报告生成和敏感结果导出。
- 权限变更、密钥引用调整和主站整改动作。

## 不变量

- 审计记录追加写入，不允许业务流程覆盖。
- 记录操作者、动作、对象、时间、结果和关联版本。
- 不记录密码、Token、完整敏感正文等秘密。
- 系统日志不能代替业务审计。

## 隐藏知识

审计存储、留存期限、归档、索引和完整性校验方式。

## 非目标

不负责运行性能监控，不推进业务状态，不保存原始网页快照。
