# 舆情监控业务模块

## 目的

从合规数据源持续观察话题、主体、情感和传播变化，形成可处置的舆情发现项。

## 拥有的业务知识

- 监测主体、别名、关键词和排除词。
- 话题聚类、情感、风险等级和传播关系口径。
- 平台优先级、时间窗口和预警阈值。
- 人工研判与事件升级流程。

## 使用共享核心

- 数据源资产目录管理平台和授权范围。
- 任务中心管理主题、平台、地区和时间窗口。
- 舆情适配器与 API 执行器采集帖子或文章。
- 内容历史处理重复、更新和互动量快照。
- 分析引擎执行规则、情感和主题判断。
- Finding、Case 和预警完成处置。

## 特有模型

- PostObservation：帖子、新闻或评论观察。
- TopicCluster：同一话题的内容集合。
- PropagationRelation：转发、引用或传播关系。
- SentimentAssessment：带证据和模型版本的倾向判断。

## 非目标

不通过绕过登录或验证码获取数据，不把作者隐私数据无边界保存，不把 AI 情感结论当作不可申诉的事实。
