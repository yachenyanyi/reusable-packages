# 数据源资产目录（Source Catalog）

## 目的

统一管理系统允许监测的数据来源，隐藏来源配置校验、版本管理、密钥引用和适配器绑定方式。

## 公开能力

- 注册来源。
- 修订来源并产生新版本。
- 启用或停用来源。
- 检查来源是否具备运行条件。
- 为一次 Run 解析不可变的 `ResolvedSource`。

## 核心模型

`SourceProfile` 由统一身份和有类型的来源配置组成：

- 通用信息：来源 ID、名称、类型、状态、负责人、适配器标识、运行策略引用、密钥引用、版本。
- 网站配置：根地址、允许域名、入口页、发现和提取方案。
- GEO 配置：供应商、模型渠道、地区、语言和能力范围。
- 舆情配置：平台、合规访问范围、接口能力和账号引用。

## 不变量

- 来源类型创建后不可跨类型修改。
- 密钥只保存引用，不保存明文。
- 历史 Run 使用过的版本不可覆盖。
- 停用来源不删除历史数据，只阻止新 Run。
- 网站来源必须声明允许域名和访问边界。

## 隐藏知识

数据库表结构、JSONB 布局、供应商字段、配置迁移、密钥存储方式和适配器注册细节。

## 非目标

不定义本次任务要查什么关键词、提示词或时间范围；这些属于任务中心。

## 依赖与使用方

被任务中心和采集引擎使用；依赖身份权限、审计追踪和基础设施适配。
