# 报告生成（Reporting）

## 目的

把任务、运行、变化、发现项和处置结果转换为可重复生成、可归档的报告。

## 公开能力

```text
generate(ReportRequest) → ReportReceipt
getReport(report_id) → ReportDescriptor
```

## ReportRequest

表达报告类型、任务或时间范围、模板版本和输出格式，不包含 SQL、文件路径或渲染引擎参数。

## 输出形式

- Word 专项报告。
- Excel 问题清单和整改台账。
- PDF 固定归档版本。

## 不变量

- 报告记录生成时使用的数据范围和模板版本。
- 同一报告可重新生成，但旧归档版本不可覆盖。
- 报告中的数字必须能回溯到查询口径。

## 隐藏知识

查询实现、模板引擎、分页、图表渲染、文件存储、格式转换和下载签名。

## 非目标

不改变 Finding 或 Case 状态，不自行触发采集，不直接决定谁应收到通知。
