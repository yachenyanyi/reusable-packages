# 站点监测业务模块

## 目的

组合共享核心能力，实现公开网站资产同步、历史内容监测、页面变化和整改复查。

## 拥有的业务知识

- 主站、研究所和研发载体的管理关系。
- 监测栏目、文章类型和时间范围。
- 问题确认、主站整改和站外问题清单流程。
- 页面删除、网站异常和地址变化的业务口径。

## 使用共享核心

- 数据源资产目录管理网站和允许域名。
- 任务中心表达全量、增量和指定页面复查。
- 网站适配器与 Web 执行器采集公开内容。
- 内容历史识别新增、更新、失联和恢复。
- 分析引擎完成关键词初筛与 AI 辅助判断。
- Case、报告和预警完成处置闭环。

## 特有输出

- 页面问题清单。
- 站点健康与页面变化记录。
- 主站整改复查结果。
- Word 专项报告、Excel 整改台账和 PDF 归档。

## 非目标

不把网站 CSS/XPath 写进业务流程，不绕过目标网站访问限制，不直接复用站点字段冒充 GEO 或舆情模型。
