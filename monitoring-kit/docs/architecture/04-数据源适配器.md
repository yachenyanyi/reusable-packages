# 数据源适配器（Source Adapter）

## 目的

封装某一类外部来源的知识，把网站、GEO 模型和舆情平台差异转换为统一采集 API 的任务参数和内部观察草稿。

## 扩展契约

- 根据 `ResolvedSource` 与任务范围生成有类型的上游任务规格。
- 解释统一 API 的版本化结果记录，产出有类型的内部 `ObservedRecordDraft`。
- 声明适配器支持的来源类型与配置版本。
- 校验本适配器拥有的来源配置。

这些是采集引擎内部扩展点，不是直接开放给后台/API 的业务接口。

## 适配器类型

- 网站适配器：网站任务参数、URL 规范化、页面结果和内容字段映射。
- GEO 适配器：模型任务参数、回答、品牌提及与引用映射。
- 舆情适配器：平台任务参数、帖子、游标结果和传播字段映射。

## 不变量

- 适配器不得直接修改 Run 状态。
- 适配器不得自行操作数据库或对象存储。
- 适配器不得决定全局重试和限速。
- 适配器不得直接指定最终 Document 身份；对应内容类型的 `ContentPolicy` 负责身份规则。
- 供应商 DTO 和原始响应不得越过适配器边界。

## 隐藏知识

上游任务参数、结果 schema、模型供应商字段、平台字段、异常字段和外部数据到内部模型的映射。

## 非目标

不承担任务调度、统一重试、凭证明文管理、快照比较和业务风险判定。

## 依赖与使用方

由采集引擎调用；通过上游任务网关访问统一 API，向采集引擎返回 `ObservedRecordDraft`。核心再经 `ContentPolicy` 形成 `Observation` 并提交给内容历史。
