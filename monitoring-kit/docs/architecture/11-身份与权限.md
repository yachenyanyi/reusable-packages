# 宿主身份与权限集成（Host Identity Integration）

## 目的

把宿主平台已经完成的身份与授权判断转换为核心可以记录的执行上下文。它是宿主集成能力，不是核心模块。

## 公开能力

- 把宿主的租户或项目映射为不透明的 `scope_key`。
- 把当前用户或服务身份映射为不透明的 `actor_ref`。
- 在调用核心之前完成授权，并把授权结果与审计信息带入上下文。
- 可选地把套餐和配额计算结果映射为 `ExecutionLimits`。

## 核心看到的上下文

```text
ExecutionContext {
  scope_key
  actor_ref
  idempotency_key
  limits?          // 已计算的限制，不是套餐名称
  trace_ref?
}
```

## 不变量

- 核心把 `scope_key` 当作数据隔离和查询边界，但不解释其业务含义。
- 核心不自行判断用户属于哪个角色或购买了哪个套餐。
- 宿主必须在调用核心前授权；核心仍校验调用数据是否处于同一 `scope_key`。
- 独立运行时可以使用固定的本地 `scope_key`，无需实现用户系统。

## 隐藏知识

JWT、Session、SSO、角色存储、套餐规则、策略缓存和身份供应商实现。

## 非目标

不管理用户、组织、角色、套餐、订单和支付；不向核心泄漏 JWT 或平台 ORM 对象。
