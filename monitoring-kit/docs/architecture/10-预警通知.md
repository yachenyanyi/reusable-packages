# 预警通知（Alerting）

## 目的

根据明确的预警方案，把可行动事件可靠投递到授权渠道，同时避免重复和噪声。

## 公开能力

```text
publish(AlertRequest) → AlertReceipt
```

`AlertRequest` 引用 Finding、Case 或运行异常，并包含预警等级和接收策略引用。

## 内部职责

- 解析接收人和渠道策略。
- 去重、静默期、升级和失败重投。
- 记录投递状态和外部回执。
- 屏蔽邮件、企业微信、短信等供应商差异。

## 不变量

- 没有授权接收范围时不得发送敏感内容。
- 重试不能造成重复通知。
- 通知正文使用的数据必须可追溯到内部记录。

## 隐藏知识

供应商 API、消息模板渲染、回执格式、重投间隔和渠道限流。

## 非目标

不判断内容是否构成风险，不修改 Case 状态，不代替审计追踪。
