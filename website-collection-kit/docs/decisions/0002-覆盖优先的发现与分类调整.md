# 覆盖优先的发现与分类调整

## Task

根据 high 官网实测结果，降低公开内容采集中的漏抓风险，并修正已经观察到的动态内容页误分类；不改变 `inspect_site`、`collect_site`、`refresh_pages` 的公共调用方式。

## Complexity Goal

- 把 URL 查询语法、sitemap 遍历和通用页面线索的易变细节继续隐藏在已有核心模块中；
- 让“发现源已遍历”和“页面确实抓到”保持可解释，避免把固定条目截断误报为收敛；
- 让常见动态 CMS 页面能够被公共解释器识别，站点专用规则仍留给 `SiteProfile`；
- 继续允许预算、时间、范围和 robots 约束控制增长，避免为了不漏抓而变成无界爬虫。

## Candidate Modules and Interfaces

### `UrlPolicy`

- 目的：拥有 URL 解析、规范化、查询身份和范围判断的不变量；
- 公共操作：保持现有 `resolve`、`canonicalize`、`decide`、`decide_auxiliary`、`decisions_for`；
- 输入：原始 URL、可选基准 URL和 `Scope`；
- 输出：稳定 URL 或 `UrlDecision`；
- 隐藏知识：查询键是否显式带 `=`、跟踪参数删除、排序和编码；
- 非目标：猜测站点业务路由或访问页面。

### `HtmlInterpreter`

- 目的：把 HTML/DOM 转成正文、字段、分类和发现线索；
- 公共操作：保持现有 `interpret`；
- 输入：传输无关的 `FetchResponse`、可选 `SiteProfile` 和 `UrlPolicy`；
- 输出：现有 `InterpretedPage`；
- 隐藏知识：`base`、脚本中的页面引用、嵌入资源、动态查询详情和通用语义路由；
- 非目标：访问网络、执行任意脚本或替代站点专用解析策略。

### `WebsiteCollectionKit`

- 目的：协调发现源、范围、队列、获取、解释、证据和覆盖报告；
- 公共操作：保持现有三个意图操作；
- 隐藏知识：常见 sitemap 入口、sitemap index 递归和预算停止时机；
- 非目标：向调用方暴露队列、框架、CDP 或供应商对象。

## Alternative Designs

### Design A：每个站点建立专用 Profile

- 通过 `route_patterns`、专用发现提示和字段选择器逐站修补；
- 优点：单站行为可精确控制；
- 风险：已发现的 URL 规范化和通用动态路由问题会在多个站点重复出现，维护成本随站点数线性放大；
- 不选择原因：当前反例（`?UUID`、`<base>`、sitemap 截断、活动/成果语义）属于可跨站复用的通用事实。

### Design B：在现有核心模块中集中处理通用事实，Profile 只保留真实站点差异

- `UrlPolicy` 负责查询身份；`HtmlInterpreter` 负责通用 HTML/DOM 线索和分类；`WebsiteCollectionKit` 负责有界发现；
- 优点：调用方和站点 Profile 不增加协调步骤，修复一次可覆盖多个站点；
- 风险：通用规则过宽会增加候选和重复；
- 控制方式：继续依赖 Scope、robots、候选/页面/时间预算，所有新增线索都进入已有 coverage 统计。

## Chosen Design

选择 Design B。

- 最深模块：`WebsiteCollectionKit`，继续隐藏完整遍历和停止逻辑；
- 最小接口：不新增公共操作或调用参数；
- 避免泄漏：不把解析器、浏览器、sitemap 节点或查询解析结构交给上层；
- 变化局部化：URL 身份变化只改 `UrlPolicy`，HTML 线索和分类只改 `HtmlInterpreter`，sitemap 遍历只改 `WebsiteCollectionKit`；
- 接受的取舍：候选数和重复数可能上升，但以覆盖报告和预算为代价换取更低漏抓风险。

## Leakage and Layering Audit

- HTTP、Playwright/CDP、存储和框架细节仍隐藏在适配器或证据端口；
- 查询 key-only 语法不会泄漏为上层特殊分支，而是成为 URL 身份的一部分；
- 不新增 pass-through 服务或全局工具模块；
- 脚本、嵌入资源和 sitemap 线索统一转换为已有 `LinkObservation`/frontier，不向调用方暴露解析中间态；
- 站点独有的路由仍通过具名 `SiteProfile`，不把单站猜测写入通用规则。
