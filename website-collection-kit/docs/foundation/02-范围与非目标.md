# 范围与非目标

## 一句话范围

对一个已知网站，在明确允许范围和资源预算内，发现公开页面并转换为可追溯、可分类、可供后续监测使用的标准网页记录。

## 本组件负责

- 从主页、显式种子、robots、sitemap、RSS、导航、列表、分页、页面链接和公开接口线索发现 URL；
- 处理普通链接、相对地址、重定向、`onclick`/`data-url` 等可安全识别的导航线索；
- 规范化 URL、限制 host/path、过滤无关路由、去重并控制遍历预算；
- 在内部选择静态 HTTP 或渲染获取，并执行有限回退；
- 提取标题、正文、摘要、发布时间、栏目、规范 URL、附件与站外来源线索；
- 分类首页、列表页、文章、通知、机构介绍、科研、产品、招聘、联系、附件等页面；
- 保存或引用原始证据；
- 报告发现来源、排除原因、失败、停止原因和覆盖信号；
- 支持全站范围采集和指定 URL 定点复查。

## 本组件明确不负责

- 不管理机构、客户、项目、租户、账号或网站确认状态；
- 不管理长期检测任务、定时调度、API Job 状态、额度和计费；
- 不保存 Document/Snapshot 历史，不判断新增、更新或删除；
- 不执行关键词检测、AI 风险判断、舆情分析或内容审核；
- 不创建 Finding、问题单、整改流程、通知或报告；
- 不修改、删除或发布目标网站内容；
- 不绕过登录、验证码、访问控制、付费墙或反自动化保护；
- 不抓取内部系统、个人账号会话或非公开接口；
- 不建设全互联网搜索引擎、通用 ETL 平台、浏览器农场管理平台或任意脚本插件平台；
- 不保证发现网站“全部页面”，只对观察到的信号和既定预算负责。

## 与相邻系统的边界

```text
长三角监测应用
  站点资产、检测规则、AI、问题、整改、报告
                    ↓
monitoring-kit
  Run、幂等恢复、Observation、历史、变化
                    ↓
统一采集 API
  Job、鉴权、分页结果、资源配额、部署与横向调度
                    ↓
website-collection-kit
  站点检查、范围遍历、网页获取、解释、证据与覆盖
                    ↓
HTTP / Playwright-CDP / 证据存储适配器
```

本组件可以在统一 API 进程内运行，也可以被 CLI 或测试宿主直接装配，但不会自行提供 HTTP 服务。

## 防膨胀准则

新增能力进入本组件前必须同时满足：

1. 它是完成已知网站发现或公开网页采集所必需的；
2. 至少能被两个真实网站或第二个真实项目复用，或者是隔离技术依赖所必需的；
3. 它能被现有边界清晰拥有，不要求引入全局 `utils`、`services` 或任意 metadata；
4. 它不把业务判断、长期任务或基础设施平台职责带入本组件；
5. 新公共接口隐藏的复杂度大于它增加的认知成本。

不满足这些条件的能力留在 `apps/<project>/` 或统一 API 宿主中。
