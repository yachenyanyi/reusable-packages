# 使用示例

## 直接采集公开网站

核心包不强制安装网络或浏览器依赖。选择适配器后由应用负责装配和关闭：

```python
import asyncio

from website_collection_kit import (
    Budget,
    CollectionIntent,
    CollectionSpec,
    HttpxAcquisition,
    Scope,
    WebsiteCollectionKit,
)


async def main():
    acquisition = HttpxAcquisition()
    kit = WebsiteCollectionKit(acquisition)
    try:
        scope = Scope.for_seeds(
            ["https://example.org/"],
            allowed_path_prefixes=["/"],
        )
        result = await kit.collect_site(
            CollectionSpec(
                collection_id="collection-20260903-001",
                site_ref="example-org",
                intent=CollectionIntent.SITE_SWEEP,
                scope=scope,
                seeds=("https://example.org/",),
                budget=Budget(max_pages=500, max_candidates=2000, max_depth=6),
            )
        )
        for page in result.pages:
            print(page.page_type.value, page.title, page.canonical_url)
    finally:
        await kit.close()


asyncio.run(main())
```

安装 HTTP 适配器依赖：

```text
pip install -e ".[http]"
```

## 使用浏览器或 CDP

需要动态渲染时，应用装配 Playwright；生产环境使用独立浏览器实例或受控 CDP 节点：

```python
from website_collection_kit import (
    HybridAcquisition,
    HttpxAcquisition,
    PlaywrightAcquisition,
    WebsiteCollectionKit,
)

acquisition = HybridAcquisition(
    static=HttpxAcquisition(),
    rendered=PlaywrightAcquisition(browser_endpoint="http://127.0.0.1:9222"),
)
kit = WebsiteCollectionKit(acquisition)
```

CDP 地址、浏览器用户目录和凭证属于部署配置，不写入 `CollectionSpec` 或 Site Profile。不要把个人浏览器会话接入采集任务。

安装浏览器适配器依赖后，还需要在部署节点安装 Playwright 浏览器：

```text
pip install -e ".[browser]"
playwright install chromium
```

## 先探测，再形成 Profile 草案

```python
from website_collection_kit import InspectionSpec, Scope, WebsiteCollectionKit

inspection = await kit.inspect_site(
    InspectionSpec(
        inspection_id="inspection-001",
        site_ref="example-org",
        seeds=("https://example.org/",),
        scope=Scope.for_seeds(["https://example.org/"]),
    )
)

print(inspection.profile_draft.route_families)
print(inspection.profile_draft.unknowns)
```

草案需要人工或宿主审核后才可以形成已发布 Profile；探测不会自动改变项目配置。

## 定点复查

```python
from website_collection_kit import CollectionIntent, CollectionSpec

result = await kit.refresh_pages(
    CollectionSpec(
        collection_id="refresh-001",
        site_ref="example-org",
        intent=CollectionIntent.TARGETED_REFRESH,
        scope=Scope.for_seeds(["https://example.org/"]),
        targets=("https://example.org/news/1",),
    )
)
```

定点复查会遵守 robots 和范围规则，但不会因为页面里的新链接扩展采集范围。
